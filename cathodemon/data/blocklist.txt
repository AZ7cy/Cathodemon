# every name under it (blocking doubleclick.net blocks ad.doubleclick.net).
# Only domains whose job is ads, tracking or telemetry are listed, so normal
# sites keep working. Add your own entries in the DNS Shield tab.
#
# Phishing look-alikes (g00gle.com, paypal-secure-login.com...) are caught by
# Cathodemon's smart blocking instead of a list, because new ones appear daily.
